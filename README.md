# Number Guessing Game

A command-line **number-guessing game** in Python. The program picks a number and gives the player
"too high / too low" feedback until they guess correctly. A clean beginner-friendly project
demonstrating loops, conditionals, and user input handling.

## Features
- Random target number each round
- Higher/lower feedback after every guess
- Tracks the number of attempts
- Simple, readable Python — good learning reference

## Run it
```bash
git clone https://github.com/furqunali/Counting-game.py.git
cd Counting-game.py
python Counting-game.py
```

## Concepts demonstrated
Loops · conditionals · `input()` handling · the `random` module · basic game state
